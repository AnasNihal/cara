# CAraShopee

A responsive, multi-page storefront concept built with HTML, CSS, and JavaScript.

The pages cover a shop catalog, product details, a cart, and supporting about, blog, contact, and login screens. This repository contains the storefront interface; payment or backend behavior should not be assumed.

## Run locally

Open `index.html` in a browser, or serve the repository root with a local static file server. The page assets and stylesheet are loaded from the repository.

## Main pages

- `index.html` — storefront landing page
- `shop.html`, `sproduct.html`, and `mproduct.html` — catalog and product pages
- `cart.html` — cart page
- `about.html`, `blog.html`, `contact.html`, and `login.html` — supporting pages
